## Choose Journey vs Use Journey

- **Choose:** discovery → trust → role selection → registration → verification.
- **Use:** list/request → match → schedule → handover → confirm → impact → feedback → repeat.

Optimise for **completed verified donation journeys**, not registrations alone.
